# Guide d'utilisation

Cette section couvre uniquement l'utilisation au quotidien : comment installer l'extension, ce que signifie chaque partie de la popup, comment interpréter les résultats et où trouver les preuves brutes en cas de faux positif.

## Chapitres

- [Installation](./install.md) — installation directe depuis Chrome Web Store, Edge Add-ons ou Firefox Add-ons, avec option Release / locale
- [Utilisation de base](./basic-usage.md) — à quoi servent les cinq zones de la popup
- [Interpréter les résultats](./results.md) — niveau de confiance, preuves, source, bouton de correction
- [Outils auxiliaires](./tools.md) — recherche dans le code source, panneau des indices bruts, copie du rapport complet

## Chemin le plus court

1. Ouvrez n'importe quelle page `http://` ou `https://`.
2. Cliquez sur l'icône StackPrism dans la barre d'outils du navigateur.
3. Consultez d'abord la vue « Essentiels » ; passez à « Tout » ou à une catégorie spécifique pour la liste complète.

Si les résultats sont trop nombreux, vous pouvez désactiver des catégories, bloquer des technologies précises ou ajouter vos propres règles depuis le [Guide de configuration](/fr/config/).
