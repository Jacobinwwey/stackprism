# Guia de uso

Esta seção cobre o uso diário: como instalar, o que cada área do popup significa, como interpretar os resultados e onde encontrar as evidências brutas ao investigar falsos positivos.

## Seções

- [Instalação e ativação](./install.md) — instalação direta pela Chrome Web Store, Edge Add-ons ou Firefox Add-ons, além de Release / build local
- [Uso básico](./basic-usage.md) — o que fazem as cinco áreas do popup
- [Interpretando resultados](./results.md) — como ler confiança, evidências, origem e o botão de correção
- [Ferramentas auxiliares](./tools.md) — pesquisa no código-fonte da página, painel de dados brutos, copiar relatório completo da stack

## Caminho mais rápido

1. Abra qualquer página `http://` ou `https://`.
2. Clique no ícone do StackPrism no canto superior direito do navegador.
3. Comece pela visualização "Destaques"; mude para "Todos" ou uma categoria específica quando precisar da lista completa.

Se os resultados forem muitos, você pode desativar categorias, bloquear tecnologias específicas ou adicionar suas próprias regras no [Guia de configuração](/pt/config/).
