# 使用ガイド

このドキュメントグループは日常的な使い方についてのみ説明します。インストール方法、ポップアップの各エリアの意味、結果の判断方法、誤検知が見つかったときの生の証拠の確認方法などを扱います。

## 章構成

- [インストールと有効化](./install.md) — Chrome Web Store、Edge ストア、Firefox Add-ons から直接インストールするか、Release / ローカルビルドを利用
- [基本的な使い方](./basic-usage.md) — ポップアップの 5 つのエリアの説明
- [結果の解読](./results.md) — 信頼度・証拠・ソース・修正ボタンの見方
- [補助ツール](./tools.md) — ウェブページソースコード検索、生の手がかりパネル、完全な技術スタックレポートのコピー

## 最短パス

1. 任意の `http://` または `https://` ページを開く。
2. ブラウザー右上の StackPrism アイコンをクリックする。
3. まず「重要」ビューを確認し、完全なリストが必要な場合は「すべて」または特定のカテゴリーに切り替える。

結果が多すぎる場合は、[設定ガイド](/ja/config/) でカテゴリーを無効化したり、特定の技術を除外したり、独自のルールを追加したりできます。
