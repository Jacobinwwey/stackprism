# 補助ツール

ポップアップ底部に 3 つのツールがあります：「検索」「生の手がかり」「すべてコピー」。検索と生の手がかりは底部からパネルを開き、最大でポップアップの高さの 60% を占めます。同じボタンを再度クリックするか、パネル内の閉じるボタンをクリックすると閉じます。「すべてコピー」はパネルを開かず、完全な技術スタックレポートを直接クリップボードにコピーします。

## ウェブページソースコード検索

使いどころ：ある検出結果が疑わしい場合や、ページに特定の文字列 / 正規表現が実際に存在するか確認したい場合。

### 入力ボックス

通常テキストと正規表現の両方に対応しています。Enter キーを押すか「検索」をクリックして実行します。

### オプション

| オプション | 説明 |
| --- | --- |
| 大文字・小文字を区別 | デフォルトはオフ。オンにすると `React` と `react` が区別される |
| 完全単語マッチ | 通常テキストモードで有効。マッチの前後が非単語文字であることを要求する（`\b` で囲む） |
| 正規表現 | 入力を JavaScript の正規表現ソースとして扱い、上記 2 つのフラグと組み合わせる |

### 出力

以下が表示されます：

- クエリ自体・パターン・ソースタイプ（DOM のシリアライズ結果か outerHTML か）・ソースコードの総バイト数
- マッチ件数（件数が多すぎる場合は「100+」と表示され、先頭 N 件のみ表示）
- 各マッチの行番号・列番号・文字オフセット、およびマッチ前後約 60 文字のコンテキストスニペット

::: tip
検索は現在のアクティブページの DOM を文字列にシリアライズしてマッチングするため、非表示要素・インラインスクリプト・コメントもカバーします。ネットワークのソースコード検索ではなく、ページ実行後にスクリプトによって変更された DOM も含まれます。
:::

## 生の手がかり

使いどころ：

- 完全な生データを確認したい場合（拡張機能に集約される前のすべてのレスポンスヘッダー / 動的スナップショット / ページ検出の生の結果）
- issue に完全な証拠を添付する場合
- カスタムルールのマッチング状況をデバッグする場合

出力は完全な JSON で、構造は以下の通りです：

```json
{
  "url": "https://example.com",
  "title": "Example",
  "generatedAt": "2026-05-10T10:00:00.000Z",
  "technologies": [
    /* マージ後の重複排除リスト */
  ],
  "resources": {
    /* リソースサマリー */
  },
  "headers": {
    /* メインドキュメントのレスポンスヘッダー */
  },
  "apiObservations": [
    /* 各 API レスポンスの url/headers/technologies */
  ],
  "frameObservations": [
    /* 各 iframe の同上 */
  ],
  "dynamicObservations": {
    /* 動的に収集されたスクリプト/スタイル/iframe/feedLinks/domMarkers */
  },
  "notes": [
    /* 方法論に関するいくつかの説明 */
  ]
}
```

### ソース → スコープ付き JSON

**特定の技術・特定のソース**に対応する JSON サブセットだけを確認したい場合は、生の手がかり全体を開く必要はありません。技術カード下部のソースタグ（例：「レスポンスヘッダー」「動的監視 · ページ操作後」）を直接クリックしてください。同じドロワーが開きますが、そのソースに関連するフィールドのみが表示され、technologies 配列はその技術のみに絞り込まれます。

ドロワーのタイトルは「生の手がかり · React · レスポンスヘッダー」のような形式になり、現在がスコープ付きビューであることがわかります。底部ツールバーの「生の手がかり」ボタンを再度クリックすると完全な JSON に戻ります。

## 完全な技術スタックレポートのコピー

ポップアップ底部の「すべてコピー」ボタンをクリックすると、現在のページの完全な技術スタックレポートがクリップボードにコピーされます。このレポートには以下が含まれます：

- 人間が読める Markdown サマリー
- `stackprism.tech_stack_report.v1` 構造化 JSON
- 現在のページの URL・タイトル・生成日時・技術総数・リソース数・メインドキュメントのレスポンスヘッダー数

コピーされるのは**現在のポップアップの結果**であり、「重要」ビューやカテゴリードロップダウンのフィルターは影響しません。設定ページのカテゴリースイッチと無効リストは引き続き有効です。issue・メモ・AI Agent の入力欄・外部テキストツールに直接貼り付けることができます。

よくある用途：

- issue / PR に完全な技術スタックのコンテキストを添付する
- サイトの技術スタックをドキュメントや知識ベースに記録する
- AI Agent にさらなる分析のために渡す
