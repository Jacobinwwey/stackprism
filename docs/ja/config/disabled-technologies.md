# 特定技術の無効化

「検出スイッチ」はカテゴリー単位でフィルタリングします。特定の技術だけを除外したい場合（カテゴリー全体を無効にしたくない場合）は、この入力ボックスを使用してください。

## 使い方

1 行に 1 つの技術名を入力します。名前は大文字・小文字を区別せず、前後の空白は自動で除去されます：

```text
Google Analytics
百度統計
WordPress プラグイン: akismet
Cloudflare
```

保存後、これらの技術はポップアップのメインリストに表示されなくなります。属するカテゴリー・信頼度・ソースに関わらず除外されます。

::: tip
名前のマッチングは `normalizeTechName(name)` を通じて行われます：空白を除去し、小文字に変換し、句読点を除去します。そのため `WordPress` と `wordpress` は等価であり、`Google Analytics` と `google-analytics` も等価です。
:::

## 除外が適切な場面

- **既に使用しているとわかっているもので表示不要なもの**：自分のサイトで毎回 Cloudflare / Vercel を表示させたくない
- **誤検知を回避する**：特定の検出ルールの誤検知率が高く、修正を待てない場合の一時的な除外
- **出力を簡略化する**：RSS / Atom / Service Worker / HTTPS などの汎用的な結果を除外してリストをよりフォーカスさせる

## 除外と検出スイッチの優先順位

両者は**重ねて**適用されます：まずカテゴリースイッチでフィルタリングし、次に無効リストでフィルタリングします。

## 生の手がかりとの関係

無効化された技術は**表示されなくなるだけ**で、生の JSON からは削除されません。「生の手がかり」パネルで取得したデータは引き続き完全であり、後で確認することができます。

## 例

Cloudflare 以外のすべての CDN を確認したい場合、CDN カテゴリーの検出は維持したまま次のように設定します：

```text
Cloudflare
```

ポップアップに Cloudflare は表示されなくなりますが、Akamai / Fastly などの他の CDN は引き続き表示されます。
