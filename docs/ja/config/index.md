# 設定ガイド

設定ページはポップアップ上部の「設定」ボタンから開くか、`chrome://extensions/` で StackPrism カードを見つけて「詳細 → 拡張機能のオプション」をクリックして開けます。

設定ページは 5 つのセクションに分かれています：

- [検出スイッチ](./categories.md) — 24 カテゴリーの有効 / 無効切り替え（無効にするとそのカテゴリーの技術はポップアップに表示されなくなる）
- [特定技術の無効化](./disabled-technologies.md) — 名前で特定の技術を正確に除外する（カテゴリーに関係なく）
- [ポップアップスタイルのカスタマイズ](./custom-css.md) — CSS を記述してポップアップ / 設定ページのスタイルを上書きする
- [カスタムルール](./custom-rules.md) — フォームまたは JSON で独自の検出ルールを追加する
- [ルール JSON のインポート / エクスポート](./json-export.md) — 複数のブラウザー / デバイス間でルールセットを同期する

## 設定の保存場所

すべての設定は `chrome.storage.sync` に保存され、ログインしている Google / Edge アカウントでデバイス間同期されます。キーは `stackPrismSettings` です。同期を望まない場合はブラウザー自身の同期機能を無効にしてください。

`chrome.storage.sync` の容量上限は 100KB で、1 つのキーあたり 8KB を超えることはできません。これが意味するのは：

- カスタムルールの数に上限がある（100 件以内が安全）
- カスタム CSS の長さに上限がある（10000 文字以内）
- 無効リストが長すぎてはいけない

実際の制限は `src/types/settings.ts` の `CUSTOM_RULE_LIMITS` によって決まり、超えた場合は保存が失敗しエラーが表示されます。

## 変更はいつ反映されるか

| 変更内容                                   | 反映タイミング                                      |
| ------------------------------------------ | --------------------------------------------------- |
| 検出スイッチ / 技術の無効化 / カスタム CSS | ポップアップを再度開いた後、即時反映                |
| カスタムルール                             | 保存後、次のページ更新 + ポップアップを再度開いた後 |
| JSON インポート                            | 上記と同じ                                          |

「設定を保存」をクリックすると即座にストレージに書き込まれます。設定ページの更新は不要です。
