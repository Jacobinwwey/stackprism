# User Guide

This section covers everyday usage: how to install the extension, what each part of the popup means, how to interpret results, and where to find raw evidence when something looks off.

## Sections

- [Install & Enable](./install.md) — install from Chrome Web Store, Edge Add-ons, or Firefox Add-ons, or use a Release/local build
- [Basic Usage](./basic-usage.md) — what the five areas of the popup do
- [Understanding Results](./results.md) — confidence levels, evidence, sources, and the correction button
- [Tools](./tools.md) — page source search, raw clues panel, copy full tech-stack report

## Quickstart

1. Open any `http://` or `https://` page.
2. Click the StackPrism icon in the browser toolbar.
3. Start with the Highlights view; switch to All or a specific category when you need the full list.

If the results are too noisy, the [Configuration Guide](/en/config/) lets you disable categories, block specific technologies, or add your own rules.
