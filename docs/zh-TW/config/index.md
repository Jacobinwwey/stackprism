# 設定指南

設定頁可以透過彈窗頂部的「設定」按鈕開啟，或者在 `chrome://extensions/` 找到 StackPrism 卡片點「詳細資訊 → 擴充功能選項」。

設定頁分五塊：

- [識別開關](./categories.md) — 24 個分類的啟停（關掉後該分類的技術不再顯示在彈窗裡）
- [停用指定技術](./disabled-technologies.md) — 用名稱精確屏蔽某些技術（無視分類）
- [自訂彈窗樣式](./custom-css.md) — 寫一段 CSS 覆蓋彈窗 / 設定頁樣式
- [自訂規則](./custom-rules.md) — 用表單或 JSON 新增自己的識別規則
- [規則 JSON 匯入匯出](./json-export.md) — 在多瀏覽器 / 多裝置同步規則集合

## 設定儲存位置

所有設定存在 `chrome.storage.sync`，會隨你登入的 Google / Edge 帳號跨裝置同步。Key 是 `stackPrismSettings`。如果不想同步，可以關閉瀏覽器自己的同步功能。

`chrome.storage.sync` 的容量上限是 100KB，單個 key 不超過 8KB。這意味著：

- 自訂規則數量有上限（約 100 條以內安全）
- 自訂 CSS 長度有上限（不超過 10000 字元）
- 停用清單不能太長

實際限制由 `src/types/settings.ts` 裡的 `CUSTOM_RULE_LIMITS` 決定，超出後儲存會失敗並顯示錯誤。

## 改完什麼時候生效

| 改動                                 | 何時生效                              |
| ------------------------------------ | ------------------------------------- |
| 識別開關 / 停用技術 / 自訂 CSS       | 重新開啟彈窗後立即生效                |
| 自訂規則                             | 儲存後下次重新整理頁面 + 重新開啟彈窗 |
| JSON 匯入                            | 同上                                  |

點「儲存設定」後會立即寫入 storage，不需要重新整理設定頁。
