# 輔助工具

彈窗底部有三個工具：「搜尋」、「原始線索」和「複製全部」。搜尋與原始線索會從底部開啟面板，最高占彈窗高度 60%；再次點擊按鈕或點面板裡的關閉按鈕即可收起。複製全部不會開啟面板，它會直接把完整技術棧報告複製到剪貼簿。

## 網頁原始碼搜尋

適用情境：你懷疑某個識別錯了，或者想確認頁面裡是否真的出現過某段字串 / 正規表達式。

### 輸入框

支援普通文字與正規表達式。按 Enter 或點「搜尋」執行。

### 選項

| 選項       | 說明                                                           |
| ---------- | -------------------------------------------------------------- |
| 區分大小寫 | 預設關閉，開啟後 `React` 和 `react` 不再等價                   |
| 全字比對   | 在普通文字模式下生效，要求比對前後是非單字字元（用 `\b` 包裹） |
| 正規表達式 | 把輸入當作 JavaScript 正規表達式來源，結合上面兩個旗標         |

### 輸出

會列出：

- 查詢本身、模式、來源類型（HTML 序列化結果還是 outerHTML）、原始碼總長度
- 符合數量（數字過大會顯示「100+」並截斷展示前 N 條）
- 每條符合的行號、欄號、字元 offset，以及符合上下文片段（命中段前後約 60 個字元）

::: tip
搜尋會把當前啟用頁面的 DOM 序列化成字串再比對，所以能覆蓋隱藏元素、inline script 和註解。它不是網路原始碼搜尋，頁面執行後被腳本改掉的 DOM 也會被算進去。
:::

## 原始線索

適用情境：

- 想看完整 raw 資料（被外掛彙總前的所有回應標頭 / 動態快照 / 頁面偵測原始結果）
- 用來給 issue 附上完整證據
- 除錯自訂規則比對情況

輸出是完整 JSON，結構如下：

```json
{
  "url": "https://example.com",
  "title": "Example",
  "generatedAt": "2026-05-10T10:00:00.000Z",
  "technologies": [/* 合併後的去重清單 */],
  "resources": {/* 資源摘要 */},
  "headers": {/* 主文件回應標頭 */},
  "apiObservations": [/* 每個 API 回應的 url/headers/technologies */],
  "frameObservations": [/* 每個 iframe 同上 */],
  "dynamicObservations": {/* 動態採集到的腳本/樣式/iframe/feedLinks/domMarkers */},
  "notes": [/* 幾句方法論說明 */]
}
```

### 來源 → scoped JSON

如果你只想看**某條技術、某個來源**對應的 JSON 子集，不用開啟整個原始線索——直接點技術卡片下方的來源標籤（比如「回應標頭」「動態監控 · 頁面互動後」）。同樣的抽屜會開啟，但只顯示該來源相關欄位，並且 technologies 陣列只保留這條技術。

抽屜標題會變成「原始線索 · React · 回應標頭」這種形式提示當前是 scoped 視圖。再點底部工具列的「原始線索」按鈕會切回完整 JSON。

## 複製完整技術棧報告

彈窗底部的「複製全部」按鈕會把當前頁面的完整技術棧報告複製到剪貼簿。這個報告包含：

- 人類可讀的 Markdown 摘要
- `stackprism.tech_stack_report.v1` 結構化 JSON
- 當前頁面的 URL、標題、產生時間、技術總數、資源數和主文件回應標頭數

它複製的是**當前彈窗結果**，不受「重點」視圖或分類下拉篩選影響；設定頁裡的分類開關和停用名單仍會生效。你可以直接貼到 issue、筆記、AI Agent 輸入框或外部文字工具裡。

常見用途：

- 提 issue / PR 時附上完整技術棧上下文
- 把某個站點的技術棧記錄到文件或知識庫
- 交給 AI Agent 做進一步分析
