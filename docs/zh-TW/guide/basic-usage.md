# 基本使用

彈窗固定高度 600px，主體是技術列表。上方放當前頁資訊和過濾控件，下方放搜尋、原始線索等輔助工具。

## 頂部工具列

```text
[StackPrism  當前頁 URL]    [主題] [設定] [複製] [重新整理]
```

- **左邊**：擴充功能名稱 + 版本號 + 當前頁 URL（截斷，hover 顯示完整）
- **右邊四個圖示按鈕**：
  - **主題**（太陽 / 月亮 / 螢幕圖示）：點擊在「自動 / 淺色 / 深色」三個狀態間循環
  - **設定**：開啟設定頁（獨立分頁）
  - **複製**：把當前頁 URL 複製到剪貼簿
  - **重新整理**：通知背景重新偵測當前頁面，已有快取結果會先留在彈窗裡

## 概覽資料

```text
22 技術    274 資源    0 回應標頭
```

- **技術**：偵測到的去重技術總數
- **資源**：當前頁面載入過的腳本 / 樣式 / iframe / 圖片等資源 URL 數量
- **回應標頭**：從主文件回應標頭裡提取出的有用 header 數量

## 分類過濾列

```text
[ 重點 5  全部 22 ]    [ 選擇分類 ▾ ]
```

- 左側是 segment 切換器，「重點」只列高可信度結果，「全部」列全部
- 右側是分類下拉，24 個分類（前端框架 / UI 框架 / CDN / WAF / 網站程式 / ...），選具體某個分類只顯示該分類的結果。每個選項後面帶計數（如「網站程式 · 4」）

## 技術列表

每條技術一個卡片：

```text
React                                         [高可信度]
- DOM 節點存在 React Fiber 標記
- 資源 URL 符合 cdn.example.com/react.production.min.js
來源：回應標頭  動態監控
識別不準確，點擊糾正
```

- **技術名稱**：可點擊，跳轉到該技術的官網或儲存庫（滑鼠懸停時右側出現外部連結圖示）
- **可信度標籤**：高（綠）/ 中（黃）/ 低（灰）
- **證據**：最多 4 行，列出讓外掛得出這個判斷的 DOM / 資源 / 回應標頭片段
- **來源**：每個標籤可點擊，**點擊會在底部彈出一個抽屜，只顯示這條技術、這條來源的原始 JSON 資料**
- **糾正按鈕**：點擊會開啟 GitHub Issue 表單，並帶上這條識別結果，方便回饋誤報 / 漏報

::: tip
如果一個頁面識別出了很多內容，建議先看「重點」視圖。它只列高可信度結果；要排查誤報或看完整技術棧時，再切到「全部」。
:::

## 底部工具列

```text
[搜尋]  [原始線索]  [複製全部]                      GitHub
```

左側工具按鈕，詳情見 [輔助工具](./tools.md)。搜尋和原始線索會從底部開啟面板，再點同個按鈕或面板裡的關閉按鈕即可收起；複製全部會直接把完整技術棧報告寫入剪貼簿。

## 捲動行為

彈窗整體高度鎖定 600px，只有**技術列表區域**自己捲動。頂部工具列、概覽、分類過濾列始終可見。

列表向下捲超過約 240px 時右下角浮出一個圓形按鈕（向上箭頭），點擊平滑捲回頂部。
