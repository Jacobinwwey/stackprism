# Przewodnik użytkownika

Ta część dokumentacji dotyczy codziennego użytkowania: jak zainstalować rozszerzenie, co oznaczają poszczególne elementy okna podręcznego, jak interpretować wyniki i gdzie szukać surowych dowodów przy fałszywych alarmach.

## Rozdziały

- [Instalacja i aktywacja](./install.md) — bezpośrednią instalację z Chrome Web Store, Edge Add-ons lub Firefox Add-ons oraz Release / lokalny build
- [Podstawowe użytkowanie](./basic-usage.md) — pięć obszarów okna podręcznego i ich funkcje
- [Interpretacja wyników](./results.md) — jak czytać poziom pewności, dowody, źródła i przycisk korekty
- [Narzędzia pomocnicze](./tools.md) — wyszukiwanie w źródle strony, panel surowych wskazówek, kopiowanie pełnego raportu stosu technologicznego

## Najkrótsza ścieżka

1. Otwórz dowolną stronę `http://` lub `https://`.
2. Kliknij ikonę StackPrism w prawym górnym rogu przeglądarki.
3. Zacznij od widoku „Kluczowe"; pełną listę zobaczysz po przełączeniu na „Wszystkie" lub wybraną kategorię.

Jeśli wyników jest zbyt dużo, możesz w [Przewodniku konfiguracji](/pl/config/) wyłączyć kategorie, zablokować konkretne technologie lub dodać własne reguły.
