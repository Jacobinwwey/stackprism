# StackPrism プライバシーポリシー

最終更新: 2026-05-12

## 概要

StackPrism（以下「本拡張機能」）は、Chrome / Edge Manifest V3 ベースのウェブ技術スタック識別ブラウザ拡張機能です。本拡張機能はお客様のプライバシーを非常に重視しています。すべてのデータ処理はお客様のブラウザ内でローカルに完結し、**いかなるリモートサーバーへもデータをアップロード、共有、または販売することはありません**。

## アクセスするデータ

「現在アクセスしているページで使用されている技術スタックを識別する」という唯一の機能を実現するため、本拡張機能はお客様がウェブページに能動的にアクセスした際に以下の情報を**ローカルで読み取り**ます。読み取られたすべての内容は**お客様のブラウザのメモリまたは chrome.storage 内でのみ処理**され、ブラウザの外に出ることは一切ありません。

### 1. ウェブサイトのコンテンツ

- 現在アクセスしているページのDOMノード構造、CSSクラス名、CSS変数、`<meta>`タグ
- ページの`window`オブジェクト上で`<script>`によって注入されたグローバル変数名（名前のみを読み取り、値は読み取りません）
- ページが読み込んだ JavaScript / CSS / iframe / 画像などのリソースのURL
- そのページで**すでに読み込まれた** JavaScriptファイルの先頭数バイト（ブラウザキャッシュを使用するため、追加のネットワークトラフィックは発生しません）。`/*! @license ... */` 著作権コメントおよびSPAに組み込まれたOAuthエントリURLの識別に使用します

### 2. ネットワーク記録

- 現在アクセスしているページのURLとタイトル
- ページが発行したXHR / Fetch / iframe / WebSocketなどのリクエストのレスポンスヘッダー（Server、X-Powered-By、Set-Cookieフィールド名など）
- ページが交渉したHTTPプロトコルバージョン（HTTP/1.1 / HTTP/2 / HTTP/3）

## データの利用目的

上記のデータは**以下の目的にのみ**使用されます。

- お客様のローカル環境で拡張機能内蔵のルールライブラリと照合し、そのページで使用されているフロントエンドフレームワーク、バックエンドサービス、CDN、CMS、ログイン、決済、アナリティクスなどの技術スタックを識別する
- 拡張機能のポップアップにてお客様ご本人に識別結果を表示する

## データの保存

- **識別結果**: `chrome.storage.session`にのみ保存され、ブラウザを閉じると消去されます。また、タブごとに独立して保存されます
- **設定**（無効化したカテゴリ、ブラックリストの技術名、カスタムルール、テーマ設定など）: `chrome.storage.sync`に保存され、ブラウザによって暗号化されてお客様のGoogle / Microsoftアカウントに同期されます。本拡張機能はお客様のアカウント内の**いかなる**データにもアクセスすることはできません
- 本拡張機能は完全なページHTML、Cookieの全値、ログイン認証情報、フォームの入力内容、パスワード、その他の機密情報を**保存しません**

## データの転送

- 本拡張機能は、お客様の閲覧データ、識別結果、個人情報、その他いかなるデータも、**いかなる**リモートサーバーにも送信しません
- テレメトリなし、広告SDKなし、サードパーティアナリティクスなし、クラウドへのエラー報告なし
- 拡張機能は2種類のネットワークリクエストのみを行い、**いずれも**お客様の個人情報や閲覧データを含みません。
  1. **現在アクセスしているページ自身がすでに読み込んだ**少数のJSファイルの先頭部分を非同期でフェッチします（ブラウザキャッシュを使用するため、追加のネットワークトラフィックは発生しません）。そのJS内の著作権コメントおよびOAuthエントリURLをローカルでスキャンするために使用します
  2. 技術ブランドのアイコンは**まず拡張機能内蔵のアイコンライブラリから読み取ります**（1300以上の主流技術のSVG / PNGをオフラインパッケージ済みで、ネットワークリクエストは発生しません）。特定の技術が内蔵アイコンライブラリにない場合のみ、`cdn.simpleicons.org`からフォールバックとして取得します（リクエストには公開技術名スラッグのみが含まれます。例: react / vuedotjs / docker。アクセス中のページURL、識別結果、その他の個人情報は含まれません）。CDNが2秒以内に読み込まれない場合、拡張機能は自動的にローカル生成のイニシャルカラーブロックにフォールバックし、識別プロセスをブロックすることは一切ありません

## 第三者への提供

- 本拡張機能はユーザーデータをいかなる第三者にも販売、共有、または転送**しません**
- 本拡張機能はユーザーデータを「技術スタックの識別」とは無関係な目的に使用**しません**
- 本拡張機能はローン、信用評価などの目的には使用**しません**

## お客様の権利

お客様はいつでも以下のことができます。

- 拡張機能のポップアップで「更新」ボタンをクリックして現在のページを再スキャンする
- 拡張機能の設定ページでルールキャッシュをリセットし、任意のカテゴリを無効化し、特定の技術名をブロックし、カスタムルールを追加する
- `chrome://extensions`から本拡張機能をアンインストールすると、すべてのローカルストレージデータがブラウザによって自動的に消去されます
